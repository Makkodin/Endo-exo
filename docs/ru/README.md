## Рекомендуемый порядок

### Локальная система

1. Проверить Docker и права пользователя.
2. Собрать образы или загрузить готовый архив.
3. Проверить image ID и runtime.
4. Подготовить референсы.
5. Выполнить `doctor`.
6. Запустить один тестовый образец.
7. Запустить основной анализ.

### Slurm-кластер

1. Проверить политику использования Docker.
2. Проверить доступность проекта и архива на compute-узлах.
3. Собрать образы один раз или получить готовый архив.
4. Распространить образы по доступным узлам.
5. Сравнить полные Docker image ID.
6. Выполнить Slurm smoke test.
7. Запустить основной анализ.

Документация отдельно описывает действия обычного пользователя и требования к администратору.
